# ふつうのダンジョン（仮）

一般的な不思議のダンジョンの試作。歩く・叩く・拾う・使う・満腹度という、ジャンルの普通の形を土台として作る。
再構築の工夫（歩数スキル・痕跡など）は今回は入れず、土台が立ってから1つずつ足して比べる。

- 遊ぶ場所： https://usouso.github.io/futsuu-dungeon/
- 設計の前提： `docs/理念.md`（守るもの）、`docs/試作仕様書.md`（今回の試作の仕様）
- 進め方：チケット（Issue）→ Claude が実装 → Codex がレビュー → 合格＋テスト全通過で取り込み

状態：公開中（2026-11-09、PR #2 を取り込み済み）。次の調整候補は、満腹度の時計の弱さと、アイテム使用時のクリア率の高さ（どちらも本人の初見試遊のあとに判断）。
