これは「好み」とは別の扱いの文書。好み（好き・嫌い）はそのときのもので流動的でよいが、理念はここに固めておき、連携する全員（Muse・Claude・Codex）が毎回ここに立ち返る。変えたくなったら、この文書を直す。

## 土台

**お手本は、任天堂と桜井さんの考え方。**（2026-11-08、本人の言葉）
入り口は誰でも直感的に分かるように広く、奥は深く。複雑な効果の組み合わせも、説明を読まなくても触れば扱える形にする。決めるときは、作る側ではなく遊ぶ人の立場で考える。
間口の広さは「一般性」の管理でもある（2026-11-09、桜井から追加）。駆け引きの深さ（ゲーム性）を上げすぎると一般性が下がるトレードオフを意識し、初心者にとっての失敗のリスクは意図的に軽くする。

## 核になる考え方

1. **楽しさから逆算する。** 仕組み → 遊んで起きること → 感じる楽しさ、の順に考える（MDA）。機能や組み合わせの数を増やす前に、「プレイヤーが何を考え、何を選び、その結果どう感じるか」を決める。

2. **個々の要素は単純に、組み合わせで深く。** 複雑さは、1つの要素に大量の説明を詰め込むことではなく、単純なルール同士が噛み合って、書いていないことが起きるところから出す。札や効果の文は文字どおりに動くのが気持ちいい。

3. **正解を作らない。** どの選択でも、何かを得て何かを失うようにする。片方だけ得をする道、相手や状況に関係なく常に得をする効果は作らない。暗記する唯一の正解ではなく、その回の手持ちと相手に合わせて「今あるものでどう切り抜けるか」を考えさせる。ただし、見つけた人がうれしい「ちょっとしたズル」や工夫の余地は、平坦に均して潰さず残す（2026-11-09、桜井から追加）。

4. **強い組み合わせは、上限ではなく入手のしやすさで止める。** 噛み合って「壊れる」くらい強くなること自体は気持ちよさのうち。強さに蓋をすると「書いてあるとおりに起きる」気持ちよさが消えるので、拾える数や機会の側で調整する。調整のとき平均化しない。長所も短所も伸ばして、デコボコ（個性）を残す（2026-11-09、桜井から追加）。

5. **分かりやすさと、判断の深さは両立させる。** 「分かりやすくする」は「判断を浅くする」ではない。必要な情報を隠すことは分かりやすさではない。比べる材料は同じ画面に置き、何が起きたかは動き・位置・音で追えるようにする。長い文字を読ませて補わない。学ばせ方は、説明文や練習場ではなく、本編を遊びながら自然に覚える形にする。前置きは短く、最初にクライマックスを見せる（2026-11-09、桜井から追加）。

6. **仕組みは、見えなければ無いのと同じ。** 目指すものは姿と中身を見せ、いつでも見られるようにする。行動とご褒美は、同じ場所・同じ瞬間に起こす。書いていない組み合わせが発動したら、その瞬間に大きく見せ、見つけた組み合わせは図鑑などに残す。当たり判定のある場所は目立たせ、関係ない背景の目立ち度は落とす（2026-11-09、桜井から追加）。

7. **負け方は「読める負け方」に。失敗は糧にする。** なぜ負けたか分かると、ほかの選択肢を試したくなる。負けても続き、足りなかったものが見えるようにする。持ち越すのは強さより、知識と選べるもの。詰んだら終わりにせず、救済を用意する。自分でリスクとご褒美を選べる形（悪魔の釜式）や、ミスすると少し楽になる形がよい。失敗の瞬間も暗くしすぎず、良いプレイは演出と音でしっかり褒める。リトライは迅速に。やられた側にも「緊張から解けてホッとする」面があるので、敗者も「面白かった」と思える構成にする（2026-11-09、桜井から追加）。

8. **運は、上振れに使う。** うれしい偶然（会心、ひらめき、成長の当たり）は運でよい。負けにつながる出来事は、理由が見えるようにする（相手がよけるのは、見える条件のときだけ、など）。

9. **手触りは「光」より「重さ」。音は拍にそろえる。** 派手さは光らせることではなく、重さ・間・音で出す。画面振動も手応え作りの道具として意図的に使う（強さ・長さ・対象に係数を付けて調整する桜井式。2026-11-09に本人が桜井の考え方でよいと判断）。動きは「やり過ぎてちょうどよい」。中割りの補間に頼るともっさりする。慣性や加速度の設計で、指に「重さ」を感じさせる。「遅さは罪」：画面遷移・リトライ・ローディングなどの待ち時間を切り詰めること自体が手触りになる。大事なメロディは、いちばん盛り上がる場面だけにとっておく。ご褒美は飽きる（飽和）ので、区切りを作ってクライマックスに置く（誇張と待ち時間の2点は2026-11-09、桜井から追加）。

10. **題材らしさを、遊びのルールそのものにする。** 題材は見た目の飾りではない。料理なら調理の意味や素材の相性、虫ならその虫らしい動きや隠れ方、洗濯なら布の柔らかさや畳み方が、強さや効果や工夫の仕組みになるようにする。数字と絵を置き換えたら何にでもなる作りにしない。

11. **思った通りに動く。** 「こう動かしたい」と入力したら、画面の中でもその通りに動く。勝手に起きるずれ（打った弾が意図せず曲がる、カメラで移動方向が変わる、攻撃が急に止まる）は、細部ではなく納得感の問題として直す。

12. **ストレスを締めて、解消する。** 「ぎゅっとストレスをかけて、パッと解消する」緩急が快感を作る。厳しい壁と楽な場所を交互に置き、平坦な坂（＝作業）を作らない（2026-11-09、桜井から追加）。

13. **ご褒美は、目の前に見せる。** 次の目的とご褒美は、手の届く範囲に見える形で置き、「先を見たい」と思わせて引っ張る。死んでやり直す前提のゲームほど、この魅力が無ければ人は残らない（2026-11-09、桜井から追加）。

14. **面白さは、1種類ではない。** 駆け引き（リスクとリターン）の他に、操作すること自体、キャラへの愛着、ごっこ遊び、工作、蓄積などがある。題材に合う面白さの種類を選んで組み合わせる（2026-11-09、桜井から追加）。

15. **音は、情報であり、ご褒美である。** 音量の優先度は物理的な大きさではなく「プレイヤーへの影響度」で決める（決着の音が最大、ヒット音が次、足音や空振りは小さく）。効果音はアタック強め・残響ほどほど。BGMの速さは攻防の速さに合わせ、情報量が多い場面では主張しすぎない。実在の題材では、リアルな音で画面の外の世界を補う。既存曲のアレンジでは主旋律を変えない（原曲がすべて正しい）。作った音は、実際の再生環境（テレビのスピーカー、ヘッドホンなど）で聞き比べる。「名作に音が悪いものなし」（2026-11-09、桜井から追加）。

16. **難しさは、作り手の感覚で決めない。** 作り手は自分のゲームに慣れている。想定よりグッと下げるのが前提。出し方には、誰でも使える簡単な方法と、難しい方法を共存させ、難しい方法を優遇する。対戦では、ハンデや「ゆらぎ」で実力差を埋める（2026-11-09、桜井から追加）。

## みんなが遊べるようにする（常に守る）

- 小さい文字と、すぐ消える文字を使わない。文字同士を重ねない。
- 情報を一度に出しすぎない。札の文字は短く（2行まで）。
- 画面の揺れは手応えのために使ってよいが、強さは控えめから始め、設定で弱める・切れるようにする。
- 画面全体を連続で光らせない（全画面の光は1手に1回まで）。
- 音量は自分で調整できるようにする（初期値は控えめ）。
- ヘルプや説明は、メニューと同じ言葉を繰り返さず、平易な言葉に噛み砕く（2026-11-09、桜井から追加）。
- ボタン設定（キーコンフィグ）を用意する。色は、色の違いだけでなく明暗の差でも区別できるようにする（2026-11-09、桜井から追加）。

## 進め方の理念

- **試作は、1つの問いに答えるためにある。** 問いを決めて、それ以外は削る。ただし、ゲームの形（目指すものと、成功・失敗が分かること）までは削らない。確かめたい体験が一周できる規模と見た目を用意する。
- **遊ばずに次の設計を決めない。** 決める → 遊ぶ → 変える、の順。一度に変えるのは1つずつ。
- **作った本人だけで判断しない。** 初めての人に、説明なしで遊んでもらう（止まった所・笑った所・やめた所を見る）。
- **数値で確かめる。** 選択のあるゲームはボットに何百回も遊ばせて、「正解の道」と「答えのない相手」ができていないか確かめる。数値をいくら変えても差が消えないときは、数値ではなく仕組みの形が原因。
- **「できた」と言う前に、自分で確かめる。** 確かめられなかった部分は「未確認」と書く（詳しくは「AIへの共通指示」）。
- **とにかく手を動かす。** 考え込んで止まるより、手数を打つ。やる気は後からついてくる（2026-11-09、桜井から追加）。
- **決断を先送りにしない。コンセプトは貫く。** 多数決で決めると平凡になる。責任を持って決めた軸は、途中でブレさせない（2026-11-09、桜井から追加）。
- **苦労は忘れる、作品は残る。** 妥協した部分だけが製品に残り続ける。効率化した上で、後悔のないところまで磨く（2026-11-09、桜井から追加）。
- **インプットとアウトプットを太くする。** たくさんの作品に触れて感性を刺激することと、作って外に出すことの両方を習慣にする（2026-11-09、桜井から追加）。
- **企画は、熱が高いうちに強火で仕上げる。** ダラダラ作らず勢いで書き上げる。責任を分散させるプランBを最初から並べない（2026-11-09、桜井から追加）。
- **温めている企画は、軽々しく話して満足しない。** 話したことで満足すると勢い（内圧）が抜ける。内圧を高めて、形にする力に変える（2026-11-09、桜井から追加）。
- **その日のうちに、こなし切る。** 判断待ちや返事を翌日に持ち越さない（2026-11-09、桜井から追加）。
- **仲間への敬意を忘れない。** 「上は下なり、下は上なり」。絶対にケンカしない。不満や指摘は後出しせず、その場で、改善案とセットで言う（2026-11-09、桜井から追加）。
- **意図と情報は、全員で共有する。** 日報や進み具合の共有で風通しを良くし、担当者だけが分かっている状態を作らない（2026-11-09、桜井から追加）。
